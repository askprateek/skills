# Hello World

This is the simplest possible skill: it exists to show the shape of a
`SKILL.md` file, not to do real work.

## What to do

When this skill is invoked, greet the user by name if you know it, otherwise
say "Hello, world!" and briefly explain that this skill is a template — point
them at [`docs/writing-skills.md`](../../docs/writing-skills.md) for how to
write their own.
