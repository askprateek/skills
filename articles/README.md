# articles

Long-form writeups that accompany this repo (e.g. posts announcing a skill,
threads explaining a design decision) live here, one directory per article.

## Layout

```
articles/YYYY-MM-slug/
  article.md     # the long-form writeup
  thread.md       # the companion social-media thread version, if any
  assets/         # images, diagrams, etc. referenced by article.md / thread.md
```

- `YYYY-MM` is the year and month the article was published.
- `slug` is a short, lowercase, hyphenated title (e.g. `2026-01-agent-skills-101`).
- `assets/` is optional — only create it if the article references local images or files.
